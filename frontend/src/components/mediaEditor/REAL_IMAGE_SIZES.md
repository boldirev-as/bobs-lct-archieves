# Использование реальных размеров изображения

## Проблема
Нужно брать актуальные размеры `<img>` элемента при каждом рендеринге, а не использовать статические размеры.

## Решение
Получаем реальные размеры изображения из `getBoundingClientRect()` и вычисляем масштаб к оригинальному изображению.

## Алгоритм

### 1. Получение актуальных размеров изображения
```typescript
// Получаем реальные размеры <img> элемента
const imageRect = imageElement.getBoundingClientRect();
const imageDisplayWidth = imageRect.width;   // 732px (из вашего примера)
const imageDisplayHeight = imageRect.height; // 384.3px (из вашего примера)

// Получаем размеры оригинального изображения
const imageNaturalWidth = imageElement.naturalWidth;   // например, 1200px
const imageNaturalHeight = imageElement.naturalHeight; // например, 600px
```

### 2. Вычисление масштаба
```typescript
// Масштаб от отображаемого размера к оригинальному
const scaleX = imageNaturalWidth / imageDisplayWidth;  // 1200 / 732 = 1.64
const scaleY = imageNaturalHeight / imageDisplayHeight; // 600 / 384.3 = 1.56
```

### 3. Преобразование координат слоя
```typescript
// Координаты слоя в отображаемом размере (как в media-editor__resizable-container)
const left = processedLayer.position[0] + storeDiff[0];
const top = processedLayer.position[1] + storeDiff[1];
const width = layer.width * processedLayer.scale;
const height = layer.height * processedLayer.scale;

// Переводим в координаты оригинального изображения
const imageLeft = left * scaleX;
const imageTop = top * scaleY;
const imageWidth = width * scaleX;
const imageHeight = height * scaleY;
```

## Пример расчета

### Исходные данные:
- **Отображаемое изображение**: 732x384.3px
- **Оригинальное изображение**: 1200x600px
- **Слой**: left=100, top=50, width=200, height=100

### Шаг 1: Масштаб
```typescript
scaleX = 1200 / 732 = 1.64
scaleY = 600 / 384.3 = 1.56
```

### Шаг 2: Координаты в оригинальном изображении
```typescript
imageLeft = 100 * 1.64 = 164
imageTop = 50 * 1.56 = 78
imageWidth = 200 * 1.64 = 328
imageHeight = 100 * 1.56 = 156
```

### Результат:
Вырезаем область (164, 78, 328x156) из оригинального изображения 1200x600.

## Преимущества

1. **Актуальность**: Размеры получаются при каждом рендеринге
2. **Точность**: Учитывается реальное масштабирование изображения
3. **Адаптивность**: Работает с любыми размерами контейнера
4. **Простота**: Использует стандартные DOM API

## Схема преобразования

```
┌─────────────────────────────────────────────────────────────┐
│                    <img> элемент                            │
│        width: 732px, height: 384.3px                       │
│        (отображаемые размеры)                              │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │        Слой (100, 50, 200x100)                   │   │
│  │        Координаты в отображаемом размере          │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
                                │
                                ▼ scaleX=1.64, scaleY=1.56
┌─────────────────────────────────────────────────────────────┐
│                Оригинальное изображение                    │
│                    1200x600px                              │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │        Область для вырезания                        │   │
│  │        (164, 78, 328x156)                          │   │
│  │        Координаты в оригинальном изображении       │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

Теперь миниатюры будут точно соответствовать видимым областям, независимо от размера контейнера!
