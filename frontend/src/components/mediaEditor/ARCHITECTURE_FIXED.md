# Исправленная архитектура системы миниатюр

## Проблема
Изначально система использовала оригинальные OCR координаты из `boundingBox.vertices`, которые не соответствовали реальным координатам отображения в `media-editor__resizable-container`.

## Решение
Теперь система использует координаты из `textLayers`, которые уже масштабированы для отображения и соответствуют реальным позициям элементов в интерфейсе.

## Ключевые изменения

### 1. `thumbnailGenerator.ts`
**Было:**
```typescript
// Использовали OCR координаты
const vertices = block.boundingBox.vertices;
const left = Math.min(...xCoords);
const top = Math.min(...yCoords);
```

**Стало:**
```typescript
// Используем координаты из textLayer
const layer = file.textLayers.find(l => l.ocrBlockIndex === blockIndex);
const left = layer.position[0];
const top = layer.position[1];
const width = layer.width || 0;
const height = layer.height || 0;
```

### 2. `useParagraphThumbnails.ts`
**Было:**
```typescript
// Отслеживали изменения в OCR блоках
const blocks = currentFile.result.result.textAnnotation.blocks;
blocks.forEach((block, index) => {
  // Проверяли OCR координаты
});
```

**Стало:**
```typescript
// Отслеживаем изменения в textLayers
const textLayers = currentFile.textLayers;
textLayers.forEach((layer) => {
  // Проверяем координаты слоя
  if (cached.coordinates.x !== layer.position[0] || 
      cached.coordinates.y !== layer.position[1] ||
      cached.coordinates.width !== (layer.width || 0) ||
      cached.coordinates.height !== (layer.height || 0)) {
    hasChanges = true;
  }
});
```

## Преимущества исправления

1. **Точность**: Миниатюры теперь показывают именно те области, которые видны в интерфейсе
2. **Синхронизация**: Координаты соответствуют реальным позициям `media-editor__resizable-container`
3. **Масштабирование**: Учитывается `layer.scale` для правильного размера
4. **Производительность**: Отслеживание изменений происходит на уровне слоев, а не OCR данных

## Поток данных

1. **Пользователь перемещает абзац** → `textLayer.position` изменяется
2. **Отслеживание изменений** → `trackParagraphChanges()` обнаруживает изменение
3. **Генерация миниатюры** → `generateParagraphThumbnail()` использует новые координаты
4. **Отображение** → Миниатюра обновляется в `TextTab`
