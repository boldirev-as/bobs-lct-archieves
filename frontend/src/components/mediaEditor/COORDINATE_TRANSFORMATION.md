# Правильное преобразование координат с учетом масштабирования изображения

## Проблема
Нужно учесть реальные рендерящиеся размеры изображения в контейнере, а не использовать координаты напрямую.

## Решение
Используем точно такую же логику масштабирования, как в `imageCanvas.tsx`, и правильно преобразуем координаты.

## Схема преобразования координат

```
┌─────────────────────────────────────────────────────────────┐
│                    Контейнер (800x600)                     │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │        Изображение (400x300)                       │   │
│  │        offsetX: 0, offsetY: 150                    │   │
│  │        displayWidth: 800, displayHeight: 300       │   │
│  └─────────────────────────────────────────────────────┘   │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │        Слой (100, 200, 200x100)                   │   │
│  │        Координаты относительно контейнера          │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
                                │
                                ▼
┌─────────────────────────────────────────────────────────────┐
│                Оригинальное изображение (1200x900)          │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐   │
│  │        Область для вырезания                        │   │
│  │        imageLeft: 150, imageTop: 300                │   │
│  │        imageWidth: 300, imageHeight: 150            │   │
│  │        Координаты относительно оригинального        │   │
│  │        изображения с учетом масштаба                │   │
│  └─────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────┘
```

## Формулы преобразования

### 1. Вычисление размеров изображения в контейнере (как в imageCanvas.tsx)
```typescript
const imageAspectRatio = imageWidth / imageHeight;
const containerAspectRatio = containerWidth / containerHeight;

if (imageAspectRatio > containerAspectRatio) {
  // Image is wider - fit to width
  displayWidth = containerWidth;
  displayHeight = containerWidth / imageAspectRatio;
  offsetX = 0;
  offsetY = (containerHeight - displayHeight) / 2;
} else {
  // Image is taller - fit to height
  displayHeight = containerHeight;
  displayWidth = containerHeight * imageAspectRatio;
  offsetX = (containerWidth - displayWidth) / 2;
  offsetY = 0;
}
```

### 2. Масштаб от контейнера к оригинальному изображению
```typescript
const scaleX = imageWidth / displayWidth;
const scaleY = imageHeight / displayHeight;
```

### 3. Преобразование координат слоя в координаты изображения
```typescript
const imageLeft = (layerLeft - offsetX) * scaleX;
const imageTop = (layerTop - offsetY) * scaleY;
const imageWidth_scaled = layerWidth * scaleX;
const imageHeight_scaled = layerHeight * scaleY;
```

## Пример расчета

### Исходные данные:
- **Оригинальное изображение**: 1200x900
- **Контейнер**: 800x600
- **Слой**: left=100, top=200, width=200, height=100

### Шаг 1: Размеры изображения в контейнере
```typescript
imageAspectRatio = 1200/900 = 1.33
containerAspectRatio = 800/600 = 1.33
// Равны, значит изображение заполняет контейнер
displayWidth = 800
displayHeight = 600
offsetX = 0
offsetY = 0
```

### Шаг 2: Масштаб
```typescript
scaleX = 1200/800 = 1.5
scaleY = 900/600 = 1.5
```

### Шаг 3: Координаты в оригинальном изображении
```typescript
imageLeft = (100 - 0) * 1.5 = 150
imageTop = (200 - 0) * 1.5 = 300
imageWidth_scaled = 200 * 1.5 = 300
imageHeight_scaled = 100 * 1.5 = 150
```

### Результат:
Вырезаем область (150, 300, 300x150) из оригинального изображения 1200x900.

## Преимущества

1. **Точность**: Учитывается реальное масштабирование изображения
2. **Соответствие**: Координаты точно соответствуют видимым областям
3. **Адаптивность**: Работает с любыми размерами контейнера и изображения
4. **Консистентность**: Использует ту же логику, что и отображение

## Проверка

Миниатюра будет показывать точно ту же область изображения, что видна в `media-editor__resizable-container`, независимо от размера контейнера и масштабирования изображения.
